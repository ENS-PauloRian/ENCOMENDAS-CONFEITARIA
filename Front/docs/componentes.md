# Catálogo de componentes

| Componente      | Responsabilidade                                                        |
|-----------------|-------------------------------------------------------------------------|
| Header          | Exibir o título do sistema e a navegação principal                      |
| Footer          | Exibir informações no rodapé                                            |
| Botao           | Padronizar os botões reutilizáveis (variantes: primário, secundário, perigo) |
| FormEncomenda   | Formulário reutilizado no cadastro e na edição de encomendas            |

## Services

| Arquivo              | Responsabilidade                                       |
|----------------------|--------------------------------------------------------|
| api.js               | Centralizar o endereço do back-end                     |
| encomendaService.js  | Funções de comunicação com a API (listar, buscar, cadastrar, alterar, excluir) |
