# Telas do sistema

| Tela               | Rota                     | Funcionalidade                                              | Situação  |
|--------------------|--------------------------|-------------------------------------------------------------|-----------|
| Home               | `/`                      | Página inicial com atalhos para as encomendas               | Concluída |
| Encomendas         | `/encomendas`            | Lista as encomendas (Read) e permite excluir (Delete)       | Concluída |
| Nova encomenda     | `/encomendas/nova`       | Formulário de cadastro de encomenda (Create)                | Concluída |
| Editar encomenda   | `/encomendas/editar/:id` | Carrega a encomenda no formulário e salva alterações (Update) | Concluída |
